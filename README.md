# FoodMunch

A responsive food-ordering landing page built with **HTML5, CSS3, and Bootstrap**. The project focuses on clean layout, mobile responsiveness, reusable Bootstrap components, and modern food-delivery UI design.

## Features

- Responsive navigation bar
- Full-screen hero section with call-to-action buttons
- "Why Choose Us?" feature cards
- Explore Menu section with food categories
- Healthy food and delivery sections
- Gift voucher modal
- Payment-method showcase
- Social-media and footer sections
- Responsive layouts for mobile, tablet, and desktop

## Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Custom styling and responsive design |
| Bootstrap 4 | Grid system, utilities, navbar, modal, spacing |
| Font Awesome | Icons |
| jQuery / Popper.js | Bootstrap interactive components |

## Run Locally

No backend or build process is required.

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

```bash
git clone https://github.com/gokul878-hue/FoodMunch.git
cd FoodMunch
```

## Project Scope

FoodMunch is currently a **frontend UI project**. It does not include user authentication, a database, payment processing, or a live food-ordering backend.
