# 🍔 FoodMunch - Responsive Food Ordering Website

A modern, vibrant, and fully responsive static landing page for a food ordering platform named **FoodMunch**. This project leverages the utility of the Bootstrap framework combined with custom CSS styling to create a seamless user experience across mobile, tablet, and desktop viewports.

---

## ✨ Features

*   **Responsive Navigation Bar:** Features a clean sticky-top header with smooth scroll links targeting specific page anchors.
*   **Hero Banner:** A viewport-height (`100vh`) immersive landing screen using CSS background covers, featuring dual distinct call-to-action buttons.
*   **"Why Choose Us?" Section:** A clean 3-column card grid system highlighting service metrics (Fine Dining, Fresh Food, and Offers).
*   **Explore Menu:** An expanded 4-column item gallery showcasing distinct meal categories utilizing Bootstrap's `shadow` wrappers and custom inline SVG directional pointers.
*   **Interactive Gift Voucher Modal:** Built natively using Bootstrap's JS modals, allowing users to trigger a pop-up window to "Redeem Gift".
*   **Social & Footer integration:** Includes custom vector iconography wrappers for popular social media handles alongside brand markers.

---

## 🛠️ Tech Stack & Dependencies

*   **HTML5:** Semantic architecture.
*   **CSS3:** Highly tailored visual rules, gradient buttons, custom container sizes, and google font integrations (`Roboto`).
*   **Bootstrap 4.5.2:** Utilized extensively for the responsive structural grid, padding/margin spacers, flexbox alignments, and utility classes (`d-none`, `d-md-block`).
*   **FontAwesome Kits:** Integration for crisp social vector badges.
*   **jQuery & Popper.js:** To power the native Bootstrap responsive navbar collapse and modal functionalities.
